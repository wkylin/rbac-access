# 权限实验室：RBAC、访问变更审批与验证器演示

这是一个独立运行的中文前端演示工程，展示员工账号、角色权限、资源范围、访问变更审批和登录验证器的完整操作流程。所有数据和交互都在浏览器本地完成。

## 启动

需要 Node.js 22.13+ 和 pnpm 11。在本工程目录执行：

```sh
pnpm install
pnpm dev
```

然后打开 `http://127.0.0.1:5180/`。可使用 `pnpm build` 构建静态文件，`pnpm preview` 预览构建结果。

## 界面主题

界面使用 Tailwind CSS 4 和 daisyUI 5，默认启用 daisyUI 内置的 `corporate` 浅色主题。`src/theme.css` 配置主题与字体，`src/style.css` 只保留布局和少量业务样式。按钮、表单、状态标签与卡片使用 daisyUI 组件类；通用排版使用 Tailwind 工具类。

## 体验顺序

所有演示账号共用密码 `Demo123!`。新建账号也使用这个演示密码；本工程不保存账号密码。

1. 以 `admin` 登录，在“角色与授权”选择 `OPERATOR`，勾选或取消一个权限，点击“预览权限变更”。输入原因和演示密码，提交提案。此时角色权限仍是旧值。
2. 点击右上角账号切换，以 `reviewer` 登录，进入“独立审批”。核对冻结的前后状态、受影响员工和影响指纹，输入理由及密码，批准或拒绝。`reviewer` 不属于 `OPERATOR` 角色，因此可以审批这项变更。
3. 返回 `admin`，在“员工目录”给员工分配角色或申请启用停用账号；在“角色与授权”调整 `GLOBAL`、`RESTRICTED`、`DENY` 资源范围；在“权限目录”停用权限项并申请重新启用。
4. 打开“我的验证器”，生成密钥。将 `otpauth://` URI 导入 Mac“密码”App 或把手动密钥添加到 TOTP 验证器，输入其生成的 6 位码启用。退出后再次登录需要动态验证码。待绑定密钥可以重新生成；停用后原密钥作废，可以重新绑定。
5. 使用“权限解释器”选择 `manager`、`OPS_HEALTH_VIEW`。受限范围可匹配 `site-a` 的具体资源；无筛选列表需要 `GLOBAL`，因此模拟接口会拒绝。该演示的菜单对宽泛列表直接按全局权限显示，避免菜单可见却立即 403。

预置的 `trainee` 账号已停用且没有角色。`EDITOR` 角色和 `CONTENT_VIEW`（内容查看）权限项已停用，供重新启用流程使用；`UNCONFIGURED_ROLE` 则用于演示未配置资源范围时的拒绝结果。

## 演示涵盖的规则

| 功能 | 实现 |
| --- | --- |
| 有效权限 | 账号、角色、权限项均启用且角色资源范围有效时才计入；按单个角色检查权限与范围，不跨角色拼接。 |
| 角色权限 | 精确权限代码列表；编辑已映射权限时保留原有未映射代码。 |
| 资源范围 | `GLOBAL`、`RESTRICTED`、`DENY`、初始未配置；多条规则任选其一，单条规则的资源条件同时满足；支持有效期、金额与币种。 |
| 访问变更 | 员工角色、角色权限、角色范围以及停用后的员工、角色、权限项重新启用，均需预览、提案和独立审批。停用操作即时生效。 |
| 审批 | 冻结前后状态、目标版本、受影响员工及 SHA-256 影响指纹；审核员需持有全局 `SYS_ACCESS_APPROVE`，且不是发起人或受影响员工。决定前重新核对权限和目标状态；过期提案不能应用。 |
| 回执与审计 | 批准时一同保存模拟状态、决定和回执；拒绝不改权限。提案可按完整 UUID 查找；审计记录不包含密码或 TOTP 密钥。 |
| 验证器 | Web Crypto 实现 30 秒、6 位、HMAC-SHA1 TOTP；支持手动密钥、`otpauth://` URI、校验启用、登录验证、停用和重新生成密钥。 |

演示环境还会阻止移除最后一组相互独立的访问管理员与审核员，以免本地数据进入无法继续审批的状态。

## 与真实系统的边界

此工程的状态保存在浏览器 `localStorage`；刷新页面后数据仍在，登录状态重新建立。可以用“恢复初始数据”清空本地提案、审计和验证器密钥。浏览器用户能查看和修改本地数据，因此这里的密码复核、审批和 TOTP **只能展示流程，不能充当生产安全控制**。多标签页会同步本地状态，但没有真正的服务器事务或跨设备一致性。生产系统必须由后端保存密钥、验证会话与权限，并原子地应用审批决定。

演示默认绑定 `127.0.0.1`。Web Crypto 需要安全上下文；请在 `localhost` / `127.0.0.1` 或 HTTPS 环境打开。
